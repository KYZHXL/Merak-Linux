## 这是什么

**YOUchat** 是一个 AI 群友机器人。它：

- 用你设定好的"人设"（性格、说话风格、世界观）在 QQ 群里聊天
- **记住**群里的每个人和发生过的事——谁帮过你、谁惹过你、群里流行什么梗
- 越聊越像"群里的一个人"，而不是冷冰冰的客服机器人
- 支持**多角色**：同一个机器人在不同群可以是不同人

简单说：**给你的 QQ 群加一个会记事的 AI 群友**。

## 你需要准备什么

| 需要的东西 | 说明 |
|---|---|
| 一台 Windows 电脑 | 目前主推 Windows（macOS/Linux 需自行折腾） |
| 一个 QQ 小号 | 机器人用这个号在群里说话。**别用主号**，建议单独注册一个小号 |
| 一个 AI 模型 API | 让机器人"会说话"的大脑。本说明书以 DeepSeek 为例（便宜、够用） |
| 基本的耐心 | 整个安装约 20-30 分钟 |

## 安装（第 1 次）

### 第 1 步：安装 Python

机器人是用 Python 写的，需要电脑先装 Python。

1. 打开 [python.org](https://www.python.org/downloads/)，下载最新版
2. 安装时**务必勾选** "Add Python to PATH"（加入系统路径）
3. 安装完成后，打开"命令提示符"（按 `Win + R`，输入 `cmd`，回车），输入：
   ```
   python --version
   ```
   能看到版本号（如 `Python 3.14.x`）就说明装好了。

### 第 2 步：下载项目

把整个 `YOUchat` 文件夹放到你喜欢的位置（比如 `C:\YOUchat` 或 `D:\我的机器人`）。放好后，文件夹里应该有 `start.py`、`README.md`、`NapCat` 等文件和文件夹。

### 第 3 步：安装项目依赖

在命令提示符里，**进入项目文件夹**：

```
cd C:\YOUchat
```

（把路径换成你实际放的位置）

然后输入：

```
pip install -r requirements.txt
```

看到 "Successfully installed" 就说明依赖装好了。装的是 Python 机器人本身要用的工具库。

### 第 4 步：安装 NapCat（QQ 连接器）

NapCat 是让机器人在 QQ 上收消息、发消息的"桥梁"。它已经放在项目的 `NapCat` 文件夹里，**不需要额外下载**。

它会弹出一个 QQ 登录窗口，**用你的 QQ 小号扫码登录**（这一步要等装好 QQ 客户端后做，见下一节）。

## 配置模型（第 1 次）

机器人需要一个"大脑"（AI 模型）。本说明书用 **DeepSeek**（国内可用、便宜、支持中文好）。

### 第 1 步：注册 DeepSeek 并拿到 API Key

1. 打开 [platform.deepseek.com](https://platform.deepseek.com)，注册登录
2. 进入「API Keys」页面 → 「创建 API Key」→ 复制那串 `sk-` 开头的密钥
3. 充一点钱（几块钱就够测试很久）

### 第 2 步：把 API Key 告诉机器人

机器人通过环境变量读你的 Key，**不要直接写进文件**（更安全）。

在命令提示符里输入（每次新开窗口都要重新设置）：

```
set YOUNCHAT_API_KEY=sk-你的密钥
```

> 想省事可以把这个命令写进 `start.py` 同目录下的一个 `.bat` 文件里，但先按上面的来，跑通了再说。

## 接入 QQ（第 1 次）

要让机器人在 QQ 群里说话，需要：**QQ 客户端** + **NapCat** + **反向 WebSocket 配置**。三步走：

### 第 1 步：安装官方 QQ 客户端

NapCat 靠注入 QQ 进程工作，所以**必须先装官方 QQ**。

1. 打开 [im.qq.com](https://im.qq.com)，下载 Windows 版 QQ
2. 安装到默认位置（NapCat 会自动找到它）
3. 用你的 **QQ 小号**登录一次，确认能正常聊天

### 第 2 步：启动 NapCat

双击运行 `NapCat` 文件夹里的 **`launcher.bat`**：

- 会弹出 NapCat 和 QQ 的窗口
- 如果弹出二维码，**用手机 QQ 扫码登录**（就是你的小号）
- 保持窗口运行，**不要关**

> ⚠️ 如果提示需要管理员权限，点"是"。
> 以后每次想开机器人，都要先让 NapCat 跑着。

### 第 3 步：配置反向 WebSocket（一次即可）

这是让 NapCat 能跟机器人"通话"的关键，**只需配置一次**，以后都记住：

1. **最简单**：运行 `python start.py`，它会在终端打印带 token 的完整链接（如 `http://127.0.0.1:6099/webui?token=xxx`），**直接点开即登录**
2. 或者手动访问 `http://127.0.0.1:6099/webui`，登录 token 在 **NapCat 启动日志的「WebUi Token:」后面**（首次启动随机生成，每个人不同）

3. 左侧找到「**网络配置**」
4. 找到「**Websocket 服务器**（Server）」→ 点击「**新增**」
5. 填写：
   - **Host**：`127.0.0.1`
   - **Port**：`6700`
   - 其他选项保持默认
6. 保存。NapCat 监听 6700，机器人连上即成功

> 这一步也可以用项目里的 `start.py` 引导完成——运行 `python start.py` 时，它会自动检测到没配反向 WS，打印带 token 的链接并一步步提示你。

### 第 4 步：把机器人加进群

用你的**主号**（或另一个号）建一个「单人测试群」，把**机器人小号**拉进群。

> 建议先建「只有你和机器人」的测试群，验证通了再进大群。

## 一键启动

以后每次想开机器人，只需要两步：

### 第 1 步：确保 NapCat 在跑

如果 NapCat 窗口还在，跳过这步。如果关了，重新双击 `NapCat\launcher.bat`。

### 第 2 步：运行一键启动

在命令提示符（已 `cd` 到项目文件夹）里输入：

```
python start.py
```

脚本会自动：
1. 检查 NapCat 是否在跑（没跑就帮你启动）
2. 检查反向 WebSocket 是否配好（没配会引导你配）
3. **自动启动 QQ 机器人**（用 settings 里存的配置）
4. 打开 Web 控制台

看到类似下面的输出就说明成功了：

```
✓ NapCat 已在运行
✓ 反向 WebSocket 已就绪
✓ QQ 机器人已启动
Web UI: http://127.0.0.1:5173
```

浏览器会自动打开控制台页面。

## 在群里聊天

### 基本规则

- **@机器人** → 它会回复（带着它的人设风格）
- **不@** → 它默默听着，把消息记进记忆，**不刷屏**

### 试试看

在测试群里，@机器人 说：

> @老猫 在吗？今天心情不太好

看它怎么回。它会用"老猫"（外冷内热的吐槽役）的风格回复你。

### 机器人怎么"记人"

- 你帮过它 → 它对你好感度上升，语气变亲近
- 你惹过它 → 好感度下降
- 群里出现的新梗 → 它会记住，合适时用出来
- 它对你的称呼、互动风格会随关系演化

## 自定义角色

机器人的人设存在 `youchat\characters\` 文件夹里，每个角色一个 `.yaml` 文件。

### 在 Web 控制台里改（推荐）

1. 浏览器打开 `http://127.0.0.1:5173`
2. 点「**角色**」tab
3. 选一个角色 → 编辑性格、说话风格、世界观、禁忌 → 保存

### 直接改文件

`characters\laomao.yaml` 长这样：

```yaml
character_id: laomao          # 角色唯一 ID
name: 老猫                    # 角色名字
personality: 外冷内热，爱吐槽   # 性格（重要）
speech_style: 短句，爱用反问    # 说话风格
background: 群里的元老成员      # 背景故事
worldview: 从不承认自己在意别人  # 世界观
taboos:                       # 绝不可违背的底线
  - text: 绝不承认自己熬夜
    keywords: [熬夜, 通宵]
    examples:
      - 老猫说自己昨晚通宵打游戏
```

复制一份改成你的角色（比如 `characters\myhero.yaml`），改掉 character_id 和内容即可。

### 关键字段怎么写

| 字段 | 作用 | 写好的技巧 |
|---|---|---|
| `personality` | 性格核心 | 具体些，如"外冷内热，爱吐槽，嘴硬心软"比"善良"好 |
| `speech_style` | 怎么说话 | 写句式特点，如"短句、爱用反问、不卖萌" |
| `background` | 背景故事 | 给角色历史感，让它有"过去" |
| `worldview` | 核心价值观 | 角色坚持什么、不信什么 |
| `taboos` | 绝对底线 | 写"绝不承认熬夜"这类，配 `keywords` 让它能识别 |

## 查看记忆沉淀库

机器人记住的东西会沉淀成文本文件，**每个角色一个**，存在项目根目录的 `memory` 文件夹里：

```
memory\laomao.txt
```

打开看看，里面分三部分：

- **事件记忆**：机器人记得的事（"阿伟帮老猫修好了电脑"）
- **社交画像**：它怎么看待每个人（"阿伟: 好感 +16 友善"）
- **近期对话**：最近聊了啥

> 也可以在 Web 控制台点「**记忆**」tab 查看，更直观。

## 常见问题（FAQ）

### Q：机器人收不到消息 / @了没反应
- 确认 NapCat 在跑（窗口没关）
- 确认反向 WebSocket 已配置（WebUI 里看是不是"已连接"）
- 确认 `bot_qq` 填的是机器人小号的 QQ 号（在 Web 控制台「启动」→「QQ 接入」里）
- 确认机器人小号真的在这个群里

### Q：机器人乱说话 / 不像设定的人设
- 检查角色文件，`personality` 和 `speech_style` 是否写清楚了
- 检查 `taboos` 是否有冲突（比如又让温柔又让毒舌）
- 模型偶尔会"跑偏"，多聊几句看是否稳定

### Q：怎么切换角色
- Web 控制台「启动」tab 里选不同角色再启动
- 或命令行：`python -m youchat --mode tui` 后用 `!switch <角色ID>`

### Q：机器人不回复普通消息（没 @ 它）
- 这是**故意的**——不 @ 只默默记忆，避免刷屏。@ 它才回

### Q：怎么让机器人更聪明 / 记性更好
- 在 Web 控制台「配置」tab 里，`embedding_model` 填 `local:BAAI/bge-small-zh-v1.5`（启用语义记忆，需要首次下载模型，约 100MB）
- 调大 `context_budget` 里的预算值（让单次能想更多事）

### Q：报错 "sk-xxx" 或 API Key 相关
- 重新执行 `set YOUNCHAT_API_KEY=你的密钥`，再跑
- 确认 DeepSeek 账户有余额

### Q：机器人用的哪个模型，能换吗
- 默认 DeepSeek。在 `youchat\config.yaml` 里改 `base_url` 和 `chat_model` 可换通义/Kimi/OpenAI 等
- 只要是对应平台的 API Key，写入环境变量即可

### Q：我想卸载 / 不想用了
- 关掉 NapCat 窗口和命令提示符即可
- 想清空记忆：删除 `youchat\data\youchat.db` 和 `memory\*.txt`
